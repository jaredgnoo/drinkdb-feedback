# DrinkDB Feedback

Public correction and evidence intake for [DrinkDB](https://drinkdb.org).

DrinkDB is a structured beverage knowledge project. This repository exists only to collect public correction requests and supporting evidence for published DrinkDB records.

## What to submit

Please open an issue when you find a public DrinkDB record that may be inaccurate, outdated, incomplete, or missing a useful first-party source.

Good submissions include:

- the affected DrinkDB page or record
- the specific statement or field that should change
- the proposed correction
- a public source or evidence link, preferably an official brand or first-party source
- optional context that helps reviewers verify the change

## What happens next

Submissions are reviewed before any change is published. Opening an issue does not directly modify DrinkDB production data.

DrinkDB may close submissions that are unverifiable, unsupported, duplicate, promotional, abusive, or unrelated to public record accuracy.

## Privacy

Do not post passwords, private account data, payment information, government IDs, private correspondence, precise personal addresses, or other sensitive personal information. Issues in this repository are public and may remain visible in GitHub history.

## Scope

This repository is for public corrections and evidence only. Product feature requests, security reports, and private support requests should not be submitted here unless DrinkDB later publishes a dedicated process for them.

---

DrinkDB principle: **Verification before Publication.**
